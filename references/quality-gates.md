# 质检与定向修正

生成后先缩小到约 10% 观察，再检查全尺寸。

## 评分

每项 1–5 分：

1. `source fidelity`：主体、数量、姿态、身份或建筑结构仍可识别。
2. `selection hierarchy`：只有一个主密度中心，局部完成度从焦点向外至少下降两级，次要信息明显被删减。
3. `negative space`：空白是构图的一部分，不是未完成事故。
4. `line authenticity`：有轻重、断续、回看和少量修正线，不像滤镜或矢量描边。
5. `mode integrity`：建筑透视/地域结构、自然地貌轮廓与坡向/尺度、人物主动态线与负形/解剖或肖像身份正确；透视夸张没有压掉原有律动。
6. `output discipline`：纯速写成稿，无手、画本、现场照片、伪文字、签名或水印。

总分至少 24/30，且不得有项目低于 3。`source fidelity` 与 `mode integrity` 必须至少为 4。

## 快速清单

- 缩略图中能否立即说出主焦点？
- 能否明确指出唯一的局部刻画区、所用主方法，以及相邻区域如何降为基础线、骨架或空白？
- 破型是否集中在真实动作、受力、遮挡或结构节点；轮廓虽不闭合，主体数量、关节与识别锚点仍然清楚？
- 能否明确指出至少一块安静纸面？
- 是否删除了 40%–60% 的低价值照片信息，或符合用户指定密度？
- 建筑是否保住轮廓、消失方向和地域特征，没有发明屋顶或窗户？
- 风景是否保住主峰、岸线、坡向、地平线与尺度关系；云雾是否通过空白切断结构，而不是被画成完整灰面？
- 人物是否保住动态、比例、年龄、表情、眼镜/发型等身份锚点？
- 动态人物的主动态线、反向支撑线和肢体负形是否仍与源图一致，而不是被近大远小改成僵直英雄姿态？
- 手指、肢体和主体数量是否正确？
- 墙面、衣服和皮肤是否仍有大片未排线区域？
- 暗部是否只聚集在结构凹处、交叠或身份锚点？
- 中间灰度是否完全来自可见排线疏密，而不是水洗、喷枪或柔和渐变？
- 是否完全没有照片滤镜、边缘检测、灰色渐变、颜色和装裱 mockup？
- 除用户提供的 `field-note` 外，是否没有任何文字？

## 定向修正

| 失败 | 只做这一项修正 |
|---|---|
| 画面过满 | 删除一半低价值线条，清空天空、墙面、衣服或皮肤中的平均排线；保留焦点不变 |
| 画面过空 | 只在主焦点补结构线和一组方向性阴影，不向所有区域补细节 |
| 局部刻画不突出 | 只保留一个完成度最高的锚点；为其选择 `ink-mass`、`directional-hatching` 或 `corrective-overdraw`，把相邻区域降为基础线、骨架或空白 |
| 局部刻画平均铺开 | 保住主锚点，删除周围一半细节；让完成度从焦点向外至少下降两级 |
| 墨块过重 | 把实黑缩回真实凹处、接触和交叠，重新打开内部缺口与周围纸面 |
| 出现晕染 | 删除全部柔和灰面；若需要中间灰度，只在主锚点使用可见且顺结构的方向性排线 |
| 轮廓太完整 | 只在 2–5 个真实动作、交叠或结构节点加入断口、穿出线、白切口和错位重启；不要平均破坏全身或整栋建筑 |
| 破型变成乱线 | 删除不顺动作或结构的随机线，恢复关键关节与识别锚点；破轮廓闭合，不破主体数量、解剖和受力关系 |
| 像滤镜 | 打断连续轮廓，增加线宽层级和边缘消失，删除等粗机械描边 |
| 建筑走样 | 恢复主体轮廓、地平线和消失方向；删除模型发明的窗、檐、装饰和文字 |
| 风景平均描满 | 恢复地貌总轮廓和唯一结构锚点；删除一半重复岩纹、雪纹、叶片或水纹，让天空、雪、雾、水面重新成为纸面空白 |
| 云雾变成灰洗 | 删除完整云轮廓与全部柔和灰面；用山体线条的消失、白切口和错位重启表现遮挡，保持主峰结构不变 |
| 肖像不像 | 恢复眼距、眉角、鼻向、嘴形、脸型和识别锚点；不要靠增加排线掩盖比例问题 |
| 人体失真 | 恢复动态线、肩胯、承重脚、手指和肢体数量；减少衣褶噪音 |
| 透视夸张压掉律动 | 先恢复源图的主动态线、反向支撑线和手臂/双腿负形，再降低近端放大；不要靠更大的鞋、拳或仰视角制造动态 |
| 手绘感不足 | 在复杂转折处增加极少量寻找线和 1–2 条修正线，同时保留基础轮廓的清晰度 |
| 出现伪文字 | 删除所有文字区域；只有用户提供的逐字 `field-note` 可以保留 |

一次迭代只修一个主要失败，重复源图锁定条件，不改变已经通过的维度。
